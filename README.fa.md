# هیرکانی

فارسی · [English](README.md)

**پیش از تاریک‌شدن جنگل، پناهی پیدا کن.** هیرکانی یک بازی دوبعدی بقا برای تلفن همراه است که از جنگل‌های هیرکانی شمال ایران الهام می‌گیرد. از طبیعت توشه بردار، زیر خاک پناهگاه بساز و داستان خانواده‌ای را شب‌به‌شب دنبال کن. زبان رابط بازی فارسی است.

![گردش در جنگل](docs/screenshots/forest.png)
![پناهگاه در شب](docs/screenshots/bunker.png)

*تصاویر از خود بازی و با استفاده از صحنه‌های آمادهٔ آزمون گرفته شده‌اند.*

## سفر در جنگل

- جنگلی زایشی را بگرد، خوراک و مصالح جمع کن و مراقب جان، گرسنگی، گرما و توانت باش.
- زیر زمین را حفر کن، راهروها و نردبان‌ها را به هم وصل کن، اتاق بساز و برای یورش شبانه آماده شو.
- صفحه‌های دفتر و ویرانه‌ها را پیدا کن، طرح پناهگاه‌های تازه را به دست بیاور و سرنخ‌های درخت کهن را دنبال کن.
- بازی در حالت افقی و بدون اینترنت اجرا می‌شود و ذخیرهٔ خودکار، نقشه، تنظیم صدا و مقدمهٔ قابل‌ردکردن دارد.

روز فرصت جست‌وجو و آماده‌شدن است؛ شب پناهگاهت را می‌آزماید. با سپیده‌دم، وقت بازیابی نیرو، تعمیر و برنامه‌ریزی برای روز بعد می‌رسد.

## راهنما و کنترل‌ها

روی صفحهٔ لمسی، دستهٔ سمت چپ را برای حرکت بکش و برای دویدن بیشتر به لبه نزدیک کن. دکمهٔ طلایی برای برداشت و تعامل است؛ دکمه‌های سمت راست کوله و ساخت‌وساز را باز می‌کنند. زیر زمین، خانه‌ای را لمس کن و فرمان حفر، ساخت یا تعمیر را به کار ببر. دکمهٔ خروج راه بازگشت به جنگل است و هنگام خطر هشدار می‌دهد. نقشه، وضعیت و مکث در بالای صفحه قرار دارند.

با صفحه‌کلید، **WASD** یا **کلیدهای جهت‌دار** برای حرکت، **E** یا **فاصله** برای تعامل و **Escape** یا **Backspace** برای بستن پنجره‌ها و مکث استفاده می‌شوند.

## فناوری و اجرای وب

بازی با جاوااسکریپت و Canvas ساخته شده است؛ منظره‌ها به‌صورت زایشی رسم می‌شوند و صدا ترکیبی از Web Audio و فایل‌های صوتی همراه بازی است. فونت نیز محلی است. نسخهٔ اندروید با Capacitor 6 همین فایل‌ها را اجرا می‌کند. برای بازی به اینترنت نیازی نیست و ذخیره روی دستگاه نگه‌داری می‌شود.

برای اجرای نسخهٔ وب با مرورگر امروزی:

```sh
python3 -m http.server 8000 --directory www
```

## نصب و ساخت نسخهٔ اندروید

از [صفحهٔ Actions](https://github.com/canoheil/hirkani/actions) خروجی `hirkani-debug-apk` یک اجرای موفق را دریافت و از حالت فشرده خارج کن. APK را به دستگاه منتقل کن و در صورت درخواست اندروید، نصب از منبع انتخاب‌شده را مجاز کن. این نسخه با کلید دیباگ امضا شده و برای آزمون است، نه انتشار تجاری. با حذف برنامه ممکن است ذخیره پاک شود و نسخه‌ای با کلید امضای متفاوت ممکن است روی نسخهٔ قبلی نصب نشود.

برای ساخت محلی به Node.js 20، Java 17 و Android SDK با platform 34 و build-tools 34.0.0 نیاز است:

```sh
npm ci
npx cap add android
bash scripts/patch-android.sh
npx cap sync android
cd android
chmod +x gradlew
./gradlew assembleDebug
```

خروجی در `android/app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد. پوشهٔ `android/` تولیدی و خارج از کنترل نسخه است؛ آن را منبع ویرایش دستی قرار نده. گردش‌کار GitHub پروژه را می‌سازد و منابع و تنظیمات ثبت‌شده را اعمال می‌کند. تگ‌های `v*` گردش‌کار انتشار یک APK با امضای دیباگ را اجرا می‌کنند؛ برای مثال نام فایل تگ `v1.0.0` برابر `Hirkani-v1.0.0.apk` خواهد بود.

## ساختار پروژه

- `www/index.html`: منطق بازی، رابط، تصویر و صدا
- `www/audio/` و `www/fonts/`: فایل‌های صوتی و فونت همراه بازی
- `resources/`: فایل‌های SVG نشان و تصویر بررسی آن
- `android-res/`: منابع آمادهٔ اندروید برای گردش‌کار ساخت
- `scripts/patch-android.sh`: اعمال منابع و تنظیمات پس از تولید پروژهٔ اندروید
- `scripts/render-icons.py`: تولید اختیاری منابع تصویری در زمان طراحی؛ به Pillow و `@resvg/resvg-js` نیاز دارد و در CI اجرا نمی‌شود
- `docs/`: تصاویر و یادداشت‌های طراحی
